人工智能训练师备考总结

2026-10-17 | notes | 3.5k 字 | 12 分钟

一、证书说明

人工智能训练师是 2020 年由人社部正式纳入《国家职业资格目录》的新职业，2021 年发布《国家职业技能标准（2021 年版）》。它的官方定义是：

使用智能训练软件，在人工智能产品实际使用过程中进行数据库管理、算法参数设置、人机交互设计、性能测试跟踪及辅助作业的人员。

等级 名称 对应职称 报考起点（一般）
五级 / 初级工 初级训练师 — 初中毕业即可
四级 / 中级工 中级训练师 — 累计从业 4 年 或 初级证 + 3 年
三级 / 高级工 高级训练师 高级工 累计从业 6 年 或 中级证 + 3 年
二级 / 技师 技师 技师 取得三级证 + 4 年
一级 / 高级技师 高级技师 高级技师 取得二级证 + 4 年

1.1 报考条件

三级（高级工）—— 满足以下之一：

  • 累计从事本职业工作 6 年（含）以上
  • 取得本职业四级 / 中级工证书后，累计从事本职业工作 3 年（含）以上
  • 取得本专业或相关专业的技工院校、技师学院毕业证书（含应届）
  • 大专及以上本专业或相关专业毕业证书（含应届）

二级（技师）—— 满足以下之一：

  • 取得本职业三级 / 高级工证书后，累计从事本职业工作 4 年（含）以上
  • 取得本职业三级 / 高级工证书的技师学院毕业生，累计从事本职业工作 3 年（含）以上
  • 硕士研究生及以上本专业或相关专业学历，累计从事本职业工作 2 年（含）以上

走竞赛通道不需要等报考年限。

1.2 技能补贴

等级 补贴金额（参考） 申领条件
初级工（五级） 500 元 在职、累计缴社保 12 个月以上
中级工（四级） 800 元 同上
高级工（三级） 1200 元 同上
技师（二级） 2000 元 同上
高级技师（一级） 3000 元 同上

申领路径：浙里办 App → 搜索”技能提升补贴” → 上传证书 → 打到社保卡。

宁波居住证积分落户：

证书等级 积分加分
初级工（五级） +5 分
中级工（四级） +10 分
高级工（三级） +15 分
技师（二级） +25 分
高级技师（一级） +40 分

租房补贴：持三级及以上技能证书，在宁波部分区县可叠加”人才租房补贴” 200–500 元/月。

个税抵扣：取得证书的当年，可按 3600 元 / 年定额抵扣个税（继续教育专项附加扣除，需在个税 App 填报）。

二、考纲范围介绍

2.1 理论部分（三级通用，180题）

题型分布：单选题 140×0.5 + 多选题 20×1 + 判断题 20×0.5 = 100 分
两场考试均为三级（高级工）竞赛——市里最高能评二级（技师）。

板块 权重 考点
一、工作组织与管理 10% 健康安全法规、数据安全原则、AI 伦理合规、任务时间管理
二、沟通与人际交往 5% 团队协作、结果展示与报告撰写、向非技术人员解释模型效果
三、数据采集/预处理/清洗/标注 25% 常见数据格式、噪声类型、标注规范、标注一致性
四、模型训练与优化 30% 监督/无监督学习原理；CNN/RNN/Transformer；PyTorch/TensorFlow；超参调优、正则化、过拟合
五、Python 编程及效果展示 20% Python 语法与数据结构、数据可视化库、模型推理脚本、损失曲线、评估报告
六、职业道德与安全法规 10% 数据隐私法律、AI 伦理准则、数据安全管理、隐私保护合规红线
合计 100%

市里补充内容：

  • Prompt 工程、RAG 基础、Agent 基础概念、智能体平台操作

2.2 实操部分

🅰 鄞州区 —— Python 数据分析 + 模型训练

平台：Python 3.10 + PyTorch 2.12 + Jupyter Notebook + Anaconda 2022.10+ + LabelMe
时长：120 分钟 / 4 个模块
总分：100 分（评价分 30% + 测试分 70%）

模块 权重 考核内容 实操工具栈
A 数据采集与预处理 15 分 ① 原始数据采集整理（5）；② 质量检测 / 识别噪音、缺失值、异常值（5）；③ 数据清洗 + 格式转换 + 质量检测（5） pandas / NumPy
B 人工智能数据集标注 30 分 ① 图像标注软件操作（10）；② 按规范完成目标类别 + 目标框标注（15）；③ 导出可视化图 + VOC/.xml / YOLO/.txt（5） LabelMe + 标注规范
C 人工智能应用模型训练 ★ 30 分 ① 导入数据集（5）；② 按要求选模型 + 参数调节完成训练（15）；③ 模型质量评估 + 核心评估参数展示（10） PyTorch / TensorFlow + sklearn
D 人工智能应用编程及场景建模 ★ 25 分 ① 数据导入清洗 + 预处理（标准化 / 划分训练集测试集）（5）；② 基于 PyTorch 加载 ANN 模型完成推理预测（15）；③ 计算精确率/召回率/F1 + 评估报告（5） PyTorch + matplotlib

🅱 市里 —— LCAgent 智能体搭建

平台：LCAgent 智能体搭建平台（教育智能体超市）+ Office
时长：120 分钟 / 3 个模块
总分：100 分（评价分 60% + 测试分 40%）

模块 权重 考核内容 实操工具栈
模块 1 业务分析 25% ① 业务流程设计（15 评价）；② 业务模块效果优化（10 评价） Office + 流程图
模块 2 智能训练 35% ① 数据处理规范制定（15 评价）；② 算法测试（20 评价） 数据处理工具 + AI 测试工具
模块 3 智能系统设计 ★ 重头 40% ① 智能系统监控和优化（30 测试）；② 人机交互流程设计（10 测试） LCAgent 平台 + Prompt 迭代

样题 1（鄞州区·回归建模）：导入 test1.csv，以”部门月度运营投入”为单变量、”部门月度利润”为目标变量构建一元线性回归；再加入”市场推广费用”构建多元回归；开启共线性诊断，输出残差直方图、标准化残差、Q-Q 图，并给出 R²、调整 R²、P 值等核心参数的分析描述。

样题 2（鄞州区·YOLO 标注）：对 50 张工人穿戴场景图做矩形框标注，类别为 Gloves / No-Gloves / Goggles / No-Goggles，遮挡或极小目标可不标注；提交标注目录截图 + 标注文件内容截图，并手动编写 data.yaml（训练路径、验证路径、类别数、四类名称）。

样题 3（市里·数据分析报表）：基于 Global_AI_Jobs.csv 完成全球 AI 岗位薪资、地区分布、技能要求、从业年限的多维数据清洗、标准化、相关性可视化，输出标准化分析报表与图表。

样题 4（市里·Prompt 迭代生成网页）：阅读业务需求文档 → 提炼关键功能点 → 编写初始 Prompt 让 AI 生成 index.html → 测试 + 多轮 Prompt 迭代（CoT / ReAct） → 提交 index.html + Prompt迭代记录.docx + Prompt设计说明.docx。

样题 5（市里·数据库运维智能体）：按运维任务清单完成数据库/表创建、SQL 查询编写与优化、备份恢复，提交 数据库运维_导出数据.csv。同分条款可能换为”数据分析智能体搭建”或”线上知识库检索智能体搭建”。

2.3 技能树

三、案例：政务热线智能问答 Agent

题目（模拟）：某区政务热线日均接入 5000 通电话，希望用 AI Agent 实现 80% 自动答复率。请给出完整方案。

拆解思路：

这个拆解就是 Loop & Harness 的核心——它不是一个模型，是一个多个子 Agent + 评估闭环的系统。市考就是要看有没有这种工程化思维。

四、模型版本说明

文中涉及的所有模型与工具版本仅供备考参考，实际比赛 / 真实落地时以发布时最新版本为准：

  • Python：3.10
  • PyTorch：2.12
  • TensorFlow、Anaconda 2022.10+、Jupyter Notebook、LabelMe：理论考纲要求，无强制版本
  • CNN 图像分类：ResNet / VGG 系列
  • RNN 时序预测：LSTM
  • Transformer 文本模型：BERT / GPT 简化版
  • RAG 检索：BGE-M3 向量化 + BM25 混合检索，BGE-Reranker 精排
  • 本地大模型：Qwen2.5-14B（政务场景示例）

⚠️ 以发布时为准：考试评分标准、平台内置模型与官方版本每年都会调整，赛前请以官方发布的最新技术规范和评分细则为准。
