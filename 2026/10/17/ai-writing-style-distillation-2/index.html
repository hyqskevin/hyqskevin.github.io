AI 仿写：风格蒸馏指南

2026-10-17 | AI | 2.4k 字 | 9 分钟

经常有人问：「我想让 AI 学某位博主的文风，帮我也写一篇。」这件事没有「一键按钮」，但可以拆成 8 步走完。

本文给出完整 SOP：先做风格蒸馏，再做 AI 仿写，最后用盲评兜底。一个完整 demo 从抓语料到出稿约 1 小时。

一、整体框架：两阶段八步法

整条流程可以压成一张表：

阶段 目标 输入 → 输出 步骤
A · 风格蒸馏 让 LLM 读懂这位作者 历史文章 → style.md 风格画像 1-4
B · AI 仿写 按画像写出新文章 style.md + 主题 → 仿写稿 5-8

1.1 步骤一览

  • 阶段 A：选作者抓语料 → 多维度提特征 → 产出 style.md → 风格验证。
  • 阶段 B：组装 system prompt → 多模型交叉生成 → 独立判官盲评 → 迭代优化。

先把 8 步的全貌记住，后面再展开细节。

二、阶段 A：风格蒸馏（4 步法）

阶段 A 的目的是把作者风格「印」成一份 LLM 能直接读懂的文件。

2.1 步骤 1 · 选 Demo 作者 + 抓语料

作者选择标准：

  • 风格稳定，至少 10 年写作积累。
  • 文章数量足够，50 篇起步，最好 100 篇以上。
  • 文章类型多样，教程、随笔、时评都有。
  • 文风鲜明，看到一句就知道是谁写的。
  • 中文优先，英文圈的方法论并不通用。

Demo 选择：阮一峰博客 ruanyifeng.com。完整仿写案例见内部仓库 08-仿写示例.md。

语料规模：最少 5 篇，15-20 篇更稳。

2.2 步骤 2 · 抓取策略（避开超时陷阱）

很多人栽在抓语料这一步——某个归档页面直接卡 36 分钟。规避方案：

  1. 用 WebSearch 找具体单篇文章 URL，不抓归档大页面。
  2. 一次 WebFetch 一篇，串行而非并发。
  3. 每篇正文截断到 2000 字以内。
  4. 30 秒无响应立刻 skip。

2.3 步骤 3 · 多维度提取风格特征

参考王建硕 9 轴指纹和 zrh091110225 的 7+1 维度，我把它扩成 10 维：

# 维度 提取方法
1 句法 平均句长、句型分布、典型句式
2 段落 段长、段首/段尾模式、段落关系
3 词汇 高频词、口语/学术混排程度、术语密度
4 排版 编号系统、括号、引用块、图表
5 开头模板 按文章类型分（周刊 / 读书 / 时评 / 随笔）
6 结尾模板 总结型 / 观点型 / 怀旧型
7 情绪基线 冷静度、幽默度、煽情度（坐标图）
8 修辞 反问、比喻、类比、排比的使用频率
9 信息密度 事实 / 观点比例、数字精确度
10 不可做清单 Do / Don’t 清单，明确避免什么

style.md 是整套 SOP 的核心交付物。要点是用 LLM 友好的结构（表格、列表）而非大段散文。

2.5 步骤 5 · 风格验证（盲测 + AI Detector）

写完 style.md 后必须验证，不能直接相信「看着像」。两层验证并行：

  1. AI Detector：用 Pangram 或 GPTZero 检测原文，Human 评分应高于 70%。
  2. 人工盲测：让独立判官盲评 5 篇原文 + 5 篇仿写，统计准确率。

Demo 数据：阮一峰案例 591 训练样本训练后 loss 从 7584 降到 213（降幅 97%）；Pangram 评分落在 50-70% Human 区间，达到可用标准。

3.2 步骤 7 · 多模型交叉生成

为什么要多模型？因为各有偏好：

  • Claude 偏学术化。
  • GPT-4 偏结构化。
  • DeepSeek 偏中文地道。
  • 同一 prompt 三家生成，质量择优。

Demo 参考：liangjfblue/writer-dna 用 DeepSeek / GLM / Claude / MiniMax 四模型交叉验证，是中文圈最完整的 pipeline。

3.3 步骤 8 · 独立判官盲评

判官盲评是整条 SOP 的最后一关，必须严格：

  1. 把原文和仿写混在一起，去掉作者名。
  2. 让第三方 LLM 或真人逐篇打分，1-10 分。
  3. 评分维度：句法相似度 / 词汇相似度 / 情感相似度 / 整体像不像。
  4. 平均分 > 7 视为合格。

Demo 参考：王建硕 wjs-distilling-style 用 9 轴指纹 + 独立判官盲测，是中文圈最严谨的方案。

3.4 步骤 9 · 迭代优化

迭代 cycle 极简：生成 → 盲评 → 发现弱点 → 改 prompt → 再生成。

常见弱点和对应 prompt 调整：

弱点 prompt 调整方向
段落太长 加「段落 ≤ 4 句」
词汇太学术 加「口语词如『捣鼓』『挺有料』」
缺少数字 加「必须用具体数字」
情绪太满 加「不煽情不浮夸」
缺少时间锚点 强制「开头必须有时间」

四、可复用工具箱

用途 工具 备注
抓语料 WebFetch / WebSearch 不要用归档大页面
风格特征提取 LLM 一次性分析 5-10 篇 输出结构化 JSON
仿写生成 Claude / GPT-4 / DeepSeek 多模型交叉
风格验证 Pangram / GPTZero AI Detector 测 human 率
盲评 第三方 LLM 或真人 关键：剥离作者名
风格持久化 skill.md / style.md 可被任何 agent 读取

五、伦理与边界（必读）

技术中立但应用有边界，使用前必须告知用户：

  1. 当代作家禁止克隆：OpenAI 已明令禁止为 Stephen King 等当代作家做风格克隆。
  2. 已故作家需谨慎：版权 + 名誉权 + 家属意愿三者都要确认。
  3. 「AI 复活亲人」需心理辅导介入：避免病态哀伤的延长。
  4. 明确标注 AI 生成：仿写文章必须注明「本文由 AI 仿写生成」。
  5. 不得用于伪造演讲 / 伪造声明：技术能做不等于应该做。

六、一页纸 Checklist（实操前自检）

  • 选好 Demo 作者（10+ 年稳定风格）
  • 抓 5-20 篇语料（时间锚点串行抓取）
  • 提取 10 个维度的风格特征
  • 写出 style.md（结构化，可被 LLM 读）
  • 准备 system prompt（模板 + 风格特征）
  • 多模型生成（至少 3 家）
  • 独立判官盲评（剥离作者名）
  • 迭代优化（基于评分调整）
  • 验证 AI Detector 评分
  • 伦理合规检查（当代作家 / 逝者 / 标注）
