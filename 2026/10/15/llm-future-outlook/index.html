大模型综合应用与AGI展望

2026-10-15 | 人工智能大模型 | 4.1k 字 | 15 分钟

本文是《大模型基础讲解》系列课程第九幕《综合与展望》的章节解读。前八幕讲了 8 大算法革命，但 54 个技术点中还有 7 个”散装”知识点无法归入单一算法锚点，它们却是工业 AI 的重要组成。这一幕用两个动作收尾：兜底——把 7 个技术点讲透；综合——用 6 大 Takeaway 把整个 72 课时串起来，并讨论 AGI 的三条路径之争。

一、这幕要讲什么

1.1 为什么需要一个”兜底章节”

前八幕分别承载了 8 大算法革命：CNN、RNN、Transformer、Diffusion、RLHF、MoE、Agent、RAG。每一幕都有一个核心锚点。但 54 个技术点里还有 7 个无法被某一幕独占，它们横向贯穿工业 AI 的各个角落：推荐、搜索、知识图谱、专家系统、机器翻译、多模态、世界模型。如果让它们继续散落在课程各处，学员会觉得”听过名字但没见过全貌”。

兜底章节的任务就两个：把技术点讲透，把课程串起来。

二、推荐系统：工业 AI 的第一桶金

推荐系统是工业 AI 的第一桶金——抖音、淘宝、美团每天亿级请求。

2.1 四阶段流水线：百万 → Top 10

工业推荐系统的工作量极大：候选物品通常以百万甚至亿计，端上却只能展示 10 个左右。所以必须分层：

四层之间可以解耦迭代，召回错了后面再准也找不回候选，所以”召回的天花板 = 推荐的天花板”。

2.2 DIN：让候选商品决定注意力

传统精排把用户历史压成一个固定向量，再与候选商品算相似度。阿里 2018 年的 DIN（Deep Interest Network）打破了这个假设：不同候选商品激活的历史兴趣不同。

在淘宝首页，”西装外套”会激活用户历史里的”衬衫/领带”，而”运动鞋”会激活”跑鞋/运动袜”。DIN 让这两个完全不同的购买意图被同一个用户表示区分开。

2.3 MMoE：8 专家多任务各取所需

推荐系统不仅要预测点击率，还要预测收藏、加购、关注、停留、成交、深度转化……任务之间常常冲突。MMoE（Multi-gate Mixture-of-Experts）的核心是：任务之间没有共同最优，但各取所需。

8 个专家是共享的，但每个任务拥有自己的门控网络——这样点击率任务和完播率任务可以在不同专家上达到峰值，避免互相拖累。

2.4 LLM 与 Agent 接管推荐

2024 年之后，LLM-Rec 和 AgentRec 路线开始挑战传统多阶段管线：

  • LLM 作为推荐器：把用户历史和候选拼成 prompt，让 LLM 直接给出 Top K。冷启动场景特别有效，零样本就能利用世界知识。
  • Agent 自主推荐：让 Agent 模拟”买家行为”，先选品类、再筛品牌、再排序，全流程可解释。
  • 挑战：推理延迟和成本远高于传统模型，目前只用在召回或解释场景。

关键论文：Cheng 2016《Wide & Deep》、Zhou 2018《DIN》、Ma 2018《MMoE》、Pi 2019《SIM》。

三、搜索引擎：RAG 的爸爸

搜索是 RAG 的爸爸——不懂 IR 不懂 RAG。

3.1 四代演化

四代不是替代而是叠加——现代搜索引擎是”BM25 + DPR + 重排”的混合体。

3.3 DPR：双塔 BERT 神经检索

Karpukhin 2020 年的 DPR（Dense Passage Retrieval）把检索从词袋时代拉进向量时代：

双塔结构允许把 p_vec 离线算好、灌进 FAISS/ScaNN，近似最近邻毫秒级返回。RAG 系统几乎都站在 DPR 与 BM25 的组合之上。

四、知识图谱：从 TransE 到 GraphRAG

知识图谱 = 结构化世界知识。

4.1 三元组世界

知识图谱的基本单元是三元组 (h, r, t)：头实体、关系、尾实体。

要把知识图谱装进模型，第一步就是学习实体和关系的向量表示。

4.2 TransE 与 GNN 三剑客

TransE（Bordes 2013）给出最直观的翻译假设：

损失函数推动”真实三元组得分高、负样本三元组得分低”。TransE 简单到几乎是字面意义的”翻译”。

但知识图谱的拓扑信息需要图神经网络捕获，绕不开三剑客：

  • GCN（Kipf 2016）：图卷积，每层聚合一阶邻居特征。
  • GraphSAGE（Hamilton 2017）：邻居采样，让模型能泛化到大图。
  • GAT（Velickovic 2018）：图 Attention，不同邻居权重不同。

这三者构成了几乎所有工业 KG 嵌入的底座。

4.3 GraphRAG：企业全局性问题的新解法

传统 RAG 在”全局性问题”上失灵——比如”这家公司五年里所有产品线投诉最多的问题是什么”，Chroma 里 100 个 chunk 救不了你。Microsoft 2024 年的 GraphRAG 提出：

把”非结构化文本”先升级成”结构化图 + 社区摘要”，再做检索。检索的不是原文 chunk，而是社区。这就是 LLM × KG 的当代写法。

五、专家系统 50 年轮回

1965 年 DENDRAL 想要做专家——2024 年 MCP / Function Calling 仍然是这个思想。50 年轮回。

5.1 黄金年代（1965–1985）

专家系统让 AI 在商业上第一次赚钱：

系统 年份 领域 成就
DENDRAL 1965 化学分析 推断有机化合物分子结构
MYCIN 1972 医疗诊断 诊断血液感染，推荐抗生素
XCON 1980 商业 帮 DEC 配置计算机订单，省下巨额成本

Feigenbaum 提出”知识就是力量”——AI 的瓶颈不是算法，是知识。这个论断深刻影响了后来 40 年的 AI 路线。

5.2 AI 寒冬（1985–2010）

专家系统没熬过自己的副作用：

  • 知识爆炸：规则越写越多，维护成本指数级上升。
  • 脆弱性：遇到规则没覆盖的情况就崩，不会”猜”。
  • 日本第五代计算机计划：砸重金做”知识库 + 推理机”硬件，1992 年宣告失败。

结果是从 1985 到 2010，AI 长期被视作”换皮统计学”。

5.3 轮回：MCP 与 Function Calling

2023–2024 年专家系统的核心思想以一种几乎原样的形式复活：

  • Function Calling（OpenAI 2023）：LLM 输出结构化函数调用，由外部工具执行。
  • MCP（Anthropic 2024-11）：Model Context Protocol，把”工具”标准化为可插拔服务。
  • MoE（Mixture of Experts）：专家混合，是”路由调度不同专家”的新版本。

DENDRAL→MYCIN→Function Calling→MCP，跨越 60 年的同一条主线。思想从来不会真正过时，只会换皮回归。

六、机器翻译：深度学习的原动力

Transformer 论文就是 NMT 论文——机器翻译推动了深度学习。

6.1 SMT 时代

1990s–2010s 主流是统计机器翻译：

代表是 IBM Models 1–5、Moses、Phrasal MT。SMT 的核心是”对齐 + 短语表 + 语言模型”，工程极其脆弱。

6.2 NMT 与 Transformer 的诞生

2014 年 Seq2Seq + Attention 让翻译进入神经时代。2017 年 Google 的《Attention Is All You Need》彻底抛弃 RNN：

机器翻译是检验深度学习新架构的最高频 benchmark——BERT、GPT、T5 都在 WMT 数据上跑过分。

6.3 多语言大模型大一统

LLM 把翻译推到了极致：

  • mBART / mT5：一个模型覆盖多语种。
  • NLLB-200（Meta 2022）：200 种语言，被很多人权组织和翻译行业引用。
  • GPT-4 / Claude：直接当成翻译器用，上下文理解 + 风格迁移能力远超专用模型。

LLM-MT 的本质：把翻译从”对齐 + 语言模型”变成”世界知识 + 上下文推理”。

七、多模态综合

多模态 = 视觉 + 语音 + 视频 + 文本统一。

7.1 技术体系全景

四块每一块都是独立巨坑，但底层共享一个范式：用大规模数据 + Transformer 学统一表征。

7.2 三件套架构

视觉理解模型几乎都是同一个骨架：

CLIP（Radford 2021）的 InfoNCE 损失是这一波范式的发令枪——把图像和文本拉到同一个向量空间。LLaVA 用一个 MLP 当 Projector，再加 7B 的 Vicuna，就能读图对话。

7.3 原生多模态与未来

三件套的瓶颈是 信息在中间被压缩过。GPT-4o、Gemini 1.5 走”原生多模态”路线：从训练开始就让模型同时看像素和文本，不分 encoder / projector。

未来三件事正在发生：

  • 多模态 Agent：把视觉 + 语音 + 文本统一到同一个 Action Loop。
  • 物理世界理解：让模型认识重力、惯性、因果。
  • 数字孪生：用视频/3D 模型生成虚拟环境，喂给 Agent 练技能。

九、AGI 路径之争

AGI 何时实现？三条路径之争：LLM 派 / 世界模型派 / 混合派。

9.1 LLM 派：Scaling Law + 推理时扩展

代表是 OpenAI 和 Anthropic。

这条路线目前最强也最烧钱。o1 / R1 在数学和代码上首次把”思考过程”显式化。

9.2 世界模型派：JEPA

代表是 Yann LeCun 和刚成立的 AMI Labs。

世界模型派的核心质疑是：LLM 不理解物理世界。JEPA 通过自监督预测未来状态，让模型学会世界运转规律。

9.3 混合派与课程结语

代表是 Google（PaLM / Gemini）和 Meta。混合派主张：

三条路径谁会赢？没有人知道。但每一个认真做事的团队都在补全同一张地图。

本节关键论文：LeCun 2022《A Path Towards Autonomous Machine Intelligence》、Assran et al. 2025《V-JEPA 2》、Hafner 2025《DreamerV3》Nature。
